# EduAI - AI-Powered Personalized Learning Ecosystem

A comprehensive Flutter application that transforms learning through AI-powered personalization, gamification, and interactive educational experiences.

## 🌟 Features

### 1. **Personalized User Onboarding**
- Google Sign-In authentication
- Comprehensive profile building:
  - Name, age, education level (Class 1-12, UG, PG, Professional)
  - Stream selection (Engineering, Medical, Commerce, Arts, Law, Competitive Exams, etc.)
  - Learning preferences (Visual, Audio, Examples, Analogies)
  - Learning pace (Fast, Normal, Slow)
  - Interest selection for personalized content
  - AI tutor personality selection (Professor, Robot, Detective, Anime Sensei, Coach)

### 2. **Smart Note Management**
- Subject-based organization
- Multi-format support:
  - PDFs
  - Images (scanned notes)
  - Text content
  - PowerPoint presentations
  - YouTube links
  - Website URLs (auto-scraping)
- RAG-based knowledge library using Gemini File Search API

### 3. **AI-Driven Teaching Experience**
- **Automated Lesson Generation**:
  - High-quality PPT slides with professional design
  - Auto-fetched relevant images
  - Real-world examples based on user interests
  - Minimal text, maximum visuals

- **Audio Lessons**:
  - Natural-sounding audio using DeepGram TTS
  - Voice synchronized with slides
  - Personality-matched voice selection

- **Adaptive Teaching**:
  - Micro-lessons with chunked content
  - Real-life scenarios and industry examples
  - Customized analogies from user interests
  - Interactive "Ask the Teacher" feature

### 4. **Comprehensive Assessment**
- **Quiz Mode**:
  - MCQs, True/False, Fill in the blanks, Numerical problems
  - Adaptive difficulty based on performance
  - Instant feedback with explanations

- **Interactive Game Mode**:
  - HTML5 games generated by Gemini API
  - Topic-specific themes (molecule builder for chemistry, velocity simulator for physics, etc.)
  - Engaging, concept-reinforcing gameplay
  - Replayable with levels and rewards

### 5. **Memory Enhancement**
- Smart flashcards with spaced repetition (SM-2 algorithm)
- Match-the-pair activities
- Rapid-fire recall mode
- Automated scheduling for optimal retention

### 6. **Voice Mode - Conversational Learning**
- Full Socratic-dialogue voice tutor
- AI speaks via DeepGram TTS
- Speech-to-text using device microphone
- Oral quizzes and concept checks
- Real-time application discussions

### 7. **RAG System (Retrieval Augmented Generation)**
- Powered by Gemini File Search API
- Vector-based semantic search
- Grounded responses from user's uploaded content
- Custom metadata for filtering
- Citation support for fact-checking

### 8. **Gamification Layer**
- **Streak System**:
  - Daily learning streaks with rewards
  - XP points for activities
  - Visual streak calendar

- **Achievements & Badges**:
  - 10 Quizzes Completed
  - First Subject Mastered
  - 100 Flashcards Reviewed
  - Perfect Score badges
  - Streak milestones (3-day, 7-day, 30-day)

- **Progress Map**:
  - Visual level-based progression
  - Topic completion tracking
  - Unlockable themes and rewards

### 9. **Study Planning & Reminders**
- AI-generated study schedules
- Revision cycle recommendations
- Daily task management
- Smart notifications
- Push reminders based on past behavior

## 🚀 Setup Instructions

### Prerequisites
- Flutter SDK (≥3.0.0)
- Dart SDK
- Android Studio / VS Code
- Firebase account
- Google Cloud account (for Gemini API)
- DeepGram account (for audio)

### Step 1: Clone and Install Dependencies
```bash
cd edtech-app
flutter pub get
```

### Step 2: Firebase Setup
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a new project
3. Add Android/iOS apps
4. Download `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
5. Place them in:
   - Android: `android/app/google-services.json`
   - iOS: `ios/Runner/GoogleService-Info.plist`

6. Enable Google Sign-In in Firebase Authentication

### Step 3: Gemini API Setup
1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Create an API key
3. Create a configuration file:

```dart
// lib/config/api_config.dart
class ApiConfig {
  static const String geminiApiKey = 'YOUR_GEMINI_API_KEY';
  static const String deepgramApiKey = 'YOUR_DEEPGRAM_API_KEY';
}
```

**IMPORTANT**: Never commit API keys to version control. Use environment variables or a secure vault.

### Step 4: DeepGram API Setup
1. Go to [DeepGram Console](https://console.deepgram.com/)
2. Sign up for free tier
3. Generate API key
4. Add to `api_config.dart` (as shown above)

### Step 5: Generate Hive Adapters
```bash
flutter packages pub run build_runner build
```

### Step 6: Run the App
```bash
flutter run
```

## 🔑 API Integration Details

### Gemini File Search (RAG System)

#### Creating a File Search Store
```dart
final geminiService = GeminiService(apiKey: ApiConfig.geminiApiKey);
final storeId = await geminiService.createFileSearchStore('Mathematics');
```

#### Uploading and Indexing Notes
```dart
final operation = await geminiService.uploadToFileSearchStore(
  fileSearchStoreName: storeId,
  file: File('path/to/notes.pdf'),
  displayName: 'Chapter 1 - Calculus',
  customMetadata: {
    'chapter': '1',
    'topic': 'Calculus',
  },
);

// Wait for indexing to complete
await geminiService.waitForOperation(operation['name']);
```

#### Querying with RAG
```dart
final response = await geminiService.generateContentWithFileSearch(
  prompt: 'Explain the concept of derivatives',
  fileSearchStoreNames: [storeId],
  userProfile: currentUserProfile,
  metadataFilter: 'chapter="1"',
);
```

### DeepGram TTS Integration
```dart
final deepgramService = DeepgramService(apiKey: ApiConfig.deepgramApiKey);

// Generate audio from text
final audioPath = await deepgramService.textToSpeech(
  text: 'Welcome to your AI-powered learning session',
  model: 'aura-asteria-en',
  fileName: 'welcome.mp3',
);

// Use personality-matched voice
final voiceModel = deepgramService.getVoiceForPersonality(user.aiPersonality);
```

## 📊 Database Schema

### Hive Boxes
- `userProfiles` - User profile data
- `subjects` - Subject information with File Search Store IDs
- `notes` - Uploaded notes with Gemini File IDs
- `lessons` - Generated lessons with slides
- `quizzes` - Quiz data and results
- `flashcards` - Flashcard decks
- `achievements` - Achievement status
- `studyPlans` - Study schedules
- `streak` - Daily streak tracking

## 🔐 Security Best Practices

1. **API Keys**: Never hardcode API keys in source code
2. **User Data**: All data stored locally using Hive encryption
3. **Authentication**: Firebase Auth with Google Sign-In
4. **File Uploads**: Validate file types and sizes before upload
5. **Rate Limiting**: Implement request throttling for API calls

## 🐛 Known Issues & Limitations

1. **Free Tier Limits**:
   - Gemini API: Limited requests per minute
   - DeepGram: 45,000 minutes of audio per month (free tier)
   - File Search: 1GB storage on free tier

2. **Performance**:
   - Large PDF processing may take time
   - Audio generation is network-dependent

3. **Platform Support**:
   - Voice input requires microphone permissions
   - Some features may not work on web platform
